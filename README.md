# مدل تحلیلی سبد معیشت خانوار ایران
## Iran Household Living Basket Analytical Model

مدل محاسباتی و داشبورد تحلیلی برای برآورد روند هزینه‌های معیشت یک خانوار مرجع شهری در ایران طی دوره ۱۳۹۶ تا ۱۴۰۵.

این پروژه با هدف تحلیل تغییرات هزینه زندگی، تورم معیشتی، قدرت خرید، رشد واقعی دارایی‌ها و مقایسه عملکرد بازارها نسبت به هزینه‌های پایه خانوار طراحی شده است.

---

# 🎯 اهداف پروژه

- ساخت مدل بازتولیدپذیر محاسبه هزینه معیشت خانوار
- تحلیل روند تغییرات هزینه‌ای در بازه بلندمدت
- مقایسه تورم سبد معیشت با شاخص‌های رسمی
- بررسی رابطه درآمد خانوار و هزینه‌های زندگی
- تحلیل رشد واقعی دارایی‌ها پس از تعدیل با تورم معیشتی

---

# 🏠 تعریف خانوار مرجع

مدل بر اساس یک خانوار شهری فرضی شامل:

- ۴ نفر اعضای خانواده
- والدین + دو فرزند
- موقعیت مرجع: مناطق جنوبی و میانی تهران

طراحی شده است.

این خانوار صرفاً یک ساختار تحلیلی برای مقایسه روندها بوده و نماینده تمام خانوارهای کشور نیست.

---

# 📊 سرفصل‌های مدل هزینه‌ای

مدل شامل بخش‌های زیر است:

| بخش | توضیح |
|-|-|
| خوراکی‌ها | ۲۳ قلم کالای پایه غذایی |
| مسکن | اجاره واحد ۶۰ متری |
| انرژی | آب، برق، گاز |
| سلامت | درمان و بیمه |
| آموزش | هزینه‌های تحصیلی |
| حمل‌ونقل | مترو و تاکسی |
| ارتباطات | اینترنت و مخابرات |
| کالاهای بادوام | کالاهای وابسته به ارز |
| پوشاک | چرخه جایگزینی پوشاک خانوار |

# 📈 قابلیت‌های داشبورد

## تحلیل تورم

- تورم ماهانه
- تورم نقطه به نقطه
- تورم ۱۲ ماهه
- تورم میانگین سالانه


## تحلیل قدرت خرید

- مقایسه درآمد خانوار حداقل‌بگیر با هزینه سبد
- درصد پوشش هزینه‌ها
- ارزش دلاری درآمد


## تحلیل دارایی‌ها

مقایسه رشد واقعی:

- دلار
- مسکن
- بورس
- خودرو
- اقلام مصرفی

با استفاده از شاخص تورم‌زدایی‌شده سبد معیشت.


## تحلیل آماری

- ماتریس همبستگی
- همبستگی با تاخیر زمانی
- خلاصه آماری متغیرها
